## Виртуализация

Для выполнения задания был установлен Proxmox VE 9.2.2.

В Proxmox создана виртуальная машина:
- VM ID: 100
- Name: ubuntu-test
- OS: Ubuntu Server 26.04.1 LTS
- CPU: 1 vCPU
- RAM: 2 GiB
- Disk: 10 GiB
- Virtualization: KVM/QEMU

Виртуальная машина успешно запускается и работает в среде Proxmox VE.

На виртуальной машине выполнена настройка сети:
- основной интерфейс ens18: 192.168.243.135/24;
- VLAN 10: 192.168.10.1/24;
- VLAN 20: 192.168.20.1/24;
- WireGuard: 10.10.10.1/24.

Удалённое администрирование виртуальной машины выполняется по SSH.
Также настроено подключение к серверу через VPN WireGuard.
