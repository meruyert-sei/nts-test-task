# Удалённый доступ

## SSH

Для удалённого администрирования Ubuntu Server настроен SSH-доступ.

Для подключения используется аутентификация по SSH-ключу. Это позволяет выполнять удалённое администрирование сервера без использования пароля учётной записи.

Подключение выполняется под пользователем `sysadmin`.

## WireGuard VPN

В качестве VPN-сервера установлен и настроен WireGuard.

Используется следующая конфигурация:

- VPN-интерфейс сервера: `wg0`
- VPN-адрес сервера: `10.10.10.1/24`
- VPN-адрес клиента: `10.10.10.2/32`
- UDP-порт WireGuard: `51820`

Клиент WireGuard настроен на Windows-хосте.

Работоспособность VPN была проверена с Windows-хоста. После подключения VPN-туннеля адрес сервера `10.10.10.1` успешно доступен с клиента.

Также было проверено SSH-подключение к серверу через VPN-туннель по адресу `10.10.10.1`.

Приватные SSH- и WireGuard-ключи в Git-репозитории не хранятся. В файле `configs/wg0.conf.example` приватный ключ заменён на `<REDACTED>`.
