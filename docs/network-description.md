## Для чего используется разделение на VLAN

VLAN позволяет логически разделить одну физическую сеть на несколько
изолированных сетевых сегментов.

Например, VLAN 10 можно использовать для рабочих компьютеров сотрудников,
а VLAN 20 — для серверов или другого типа устройств.

Такое разделение позволяет ограничивать обмен трафиком между разными
группами устройств, применять к ним разные правила firewall и уменьшать
broadcast-трафик.

В данной конфигурации VLAN 10 и VLAN 20 созданы на одном физическом
интерфейсе ens18 с использованием стандарта IEEE 802.1Q.
